# MIT 6.0002: Introduction to Computational Thinking and Data Science 📊

This repository contains my coursework, simulations, and algorithmic modeling for **MIT 6.0002**. 

As the advanced follow-up to 6.100L, this curriculum bridges the gap between software engineering and data science. The focus of this repository is on utilizing computation to model real-world phenomena, process data, and solve complex optimization problems under constraints.

## 🧠 Core Concepts Mastered
- **Graph Theory & Search Algorithms:** Designing node/edge models, and implementing Depth-First Search (DFS) and Breadth-First Search (BFS) for shortest-path routing.
- **Optimization Problems:** Solving Knapsack problems using greedy algorithms, decision trees, and dynamic programming for optimal substructure.
- **Stochastic Modeling & Simulations:** Engineering Random Walks, Monte Carlo simulations, and computing probabilities to model systems with inherent uncertainty.
- **Data Science & Statistics:** Curve fitting, linear regression, standard deviation, and analyzing experimental data distributions.
- **Machine Learning Fundamentals:** Feature representation, distance metrics, and implementing clustering algorithms to find patterns in unlabelled data.

## 📂 Repository Structure
* **/psets:** Solutions to the official MIT problem sets, strictly adhering to mathematical accuracy, simulation design, and plotting requirements.
* **/models:** Standalone scripts for graph traversals (DFS/BFS), Monte Carlo simulations, and dynamic programming algorithms.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Libraries:** Matplotlib, NumPy (for data visualization and statistical computing)
* **Tools:** Git, Linux/Bash
